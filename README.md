C) Case Study : Banking Management System
===============================================
1. Introduction
A Banking Management System is a C programming-based application designed to manage basic banking operations efficiently. It helps banks maintain customer account details and perform transactions such as depositing money, withdrawing money, checking account balances, and viewing customer information.
The system reduces manual work and makes banking operations easier, faster, and more accurate. It allows users to create and manage bank accounts and maintain important information such as account number, customer name, account type, and available balance.
This project demonstrates how the C programming language can be used to develop a simple banking application. It also provides practical knowledge of programming concepts such as structures, arrays, functions, loops, conditional statements, and file handling.

2. Objectives
1.To create bank accounts: Allow users to create new bank accounts by entering customer details.
2. To maintain customer records: Store and manage customer information, including account number, name, account type, and balance.
3. To deposit money: Provide a facility for customers to deposit money into their bank accounts.
4. To withdraw money: Allow customers to withdraw money from their accounts while checking the available balance.
5. To check account balance: Display the current balance available in a customer's account.
6. To search for accounts: Find customer account details using the account number.
7. To display account information: Show complete details of registered bank accounts.

3. Concept used
Variables and data types , Arrays , Structures (struct) , Functions, File, pointer, Conditional statements, Loops, Switch statements
